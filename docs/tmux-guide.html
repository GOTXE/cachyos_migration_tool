❓ ¿Qué es tmux?
💡 La Idea Simple
Imagina que tienes un escritorio dentro de tu terminal. Con tmux puedes:
  • ✅ Dividir la pantalla en múltiples ventanas (como arrancar varias aplicaciones a la vez)
  • ✅ Desconectarte sin cerrar nada (tus programas siguen corriendo en background)
  • ✅ Reconectarte cuando vuelvas (todo sigue donde lo dejaste)
  • ✅ Usar el ratón para cambiar entre ventanas automáticamente

❌ Sin tmux

Tienes una sola ventana. Si la cierras, todo se muere.

✅ Con tmux

Puedes cerrar la ventana y todo sigue corriendo. Al volver, está exactamente igual.

📦 Nivel Básico Fácil
⬇️ Paso 1: Instalar tmux
Solo necesitas ejecutar esto una vez. Si ya está instalado, ¡salta al siguiente paso!
bash src/modules/tmux_setup.sh
✅ ¿Listo? El script hace todo automáticamente. Configura tmux, instala plugins, lo deja bonito y listo para usar.
🚀 Paso 2: Crear tu primera sesión
Una sesión es como un escritorio dentro de tu terminal. Aquí crearemos uno con 3 divisiones.
bash assets/scripts/init-tmux-sessions.sh create ai-agents

Acabas de crear una sesión llamada ai-agents con 3 panes (ventanas divididas):

┌─────────────────────┬─────────────────────┐ │ │ │ │ Pane 1 (arriba iz) │ Pane 2 (arriba der)│ │ │ │ ├─────────────────────┼─────────────────────┤ │ │ │ Pane 3 (abajo, ancho) │ │ │ └─────────────────────┴─────────────────────┘
🔌 Paso 3: Conectarte a tu sesión
Ahora entramos dentro de esa sesión para empezar a usar los 3 panes.
tmux a -t ai-agents
💡 Atajo: tmux a es corto para attach. El -t ai-agents dice "conéctate a la sesión llamada ai-agents"
🖱️ Paso 4: Navegar entre ventanas
Ahora estás adentro. ¿Cómo cambias entre los 3 panes? Dos opciones:

Opción A: Con el ratón (más fácil) 🖱️

Solo mueve el ratón al pane que quieras. El borde se pone azul y el foco cambia automáticamente. Puedes escribir sin hacer clic.

Opción B: Con el teclado 🎹

Ctrl+H
Izquierda
Ctrl+L
Derecha
Ctrl+K
Arriba
Ctrl+J
Abajo
▶️ Paso 5: Ejecutar comandos en cada pane
Ahora que sabes navegar, puedes ejecutar lo que quieras en cada pane de forma independiente.
1

Haz Ctrl+H para ir al Pane 1 (izquierda)

Espera a ver el borde azul. Luego escribe:

watch -n 1 'date'

Verás la hora actualizar cada segundo.

2

Haz Ctrl+L para ir al Pane 2 (derecha)

Escribe algo diferente:

while true; do echo "Hola $(date)"; sleep 2; done

Verás un saludo cada 2 segundos.

3

Haz Ctrl+J para ir al Pane 3 (abajo)

Ahora vuelve a una consola normal:

pwd

Ves que cada pane es totalmente independiente. El comando de arriba sigue corriendo mientras usas este.

🎉 ¡Lo has hecho! Ahora tienes 3 "terminales" corriendo al mismo tiempo sin pisarse.
🔌 Paso 6: Desconectarte (sin cerrar nada)
Esto es lo chulo: Puedes cerrar tmux o incluso apagar el ordenador. Los procesos siguen corriendo.

Presiona estas teclas juntas (dentro de tmux):

Ctrl+B, D

"Ctrl+B" es el prefijo de tmux (le dice "esto es un comando de tmux"), luego "D" de "Detach" (desconectarse).

✅ Resultado: Te sales de tmux, pero los procesos en los 3 panes siguen corriendo en background.
🔄 Paso 7: Reconectarte y encontrar todo igual
Horas después, días después... ejecutas:
tmux a -t ai-agents
✅ ¡Magia! Todo está exactamente igual. Los procesos siguen corriendo. El historial se preserva. Es como si nunca te hubieras ido.
⚙️ Nivel Intermedio Medio
📋 Ver todas tus sesiones
Si tienes múltiples sesiones (múltiples "escritorios"), puedes listarlas:
tmux list-sessions

Verás algo como:

ai-agents: 1 windows (created Thu Jun 04 10:30:00 2026)
trabajo: 2 windows (created Thu Jun 04 08:15:00 2026)
💡 Cada sesión es independiente. Puedes tener una para trabajo, otra para estudio, otra para proyectos personales.
📦 Crear múltiples sesiones
Puedes crear varias sesiones y saltar entre ellas fácilmente:
tmux new-session -s trabajo
tmux new-session -s estudio
tmux new-session -s personales

Para conectarte a cualquiera:

tmux a -t trabajo # conecta a trabajo
tmux a -t estudio # conecta a estudio
⌨️ Atajos útiles dentro de tmux
Cuando estés dentro de tmux (en tu sesión), puedes hacer más cosas:
Atajo Qué hace
Ctrl+B , c Crear una nueva ventana (window) dentro de la sesión
Ctrl+B , n Ir a la siguiente ventana
Ctrl+B , p Ir a la ventana anterior
Ctrl+B , v Dividir el pane verticalmente
Ctrl+B , s Dividir el pane horizontalmente
Ctrl+B , [ Entrar en modo lectura (scroll por historial)
Ctrl+B , ] Salir del modo lectura
🎯 Crear atajos en tu shell para conectarse rápido
En lugar de escribir tmux a -t ai-agents cada vez, puedes crear un alias corto.

Abre tu archivo ~/.bashrc o ~/.zshrc y añade:

alias tma="tmux a -t ai-agents"
alias tmls="tmux list-sessions"
alias tmkill="tmux kill-session -t ai-agents"

Guarda, cierra la terminal y reabre. Ahora:

tma # Conecta a ai-agents
tmls # Lista todas las sesiones
tmkill # Cierra la sesión ai-agents
💾 Cómo funciona la persistencia automática
Tenemos 2 plugins que trabajan juntos para guardar y restaurar todo:

📸 tmux-resurrect

Guarda una "foto" del estado: qué panes tienes, qué comandos estaban ejecutándose, el historial.

⏰ tmux-continuum

Automáticamente toma una foto cada 15 minutos. Si reinicia, restaura la última foto.

✅ Resultado: Aunque apagues el ordenador, cuando lo enciendas y ejecutes tmux a -t ai-agents, todo está como lo dejaste.
🚀 Nivel Avanzado Difícil
✂️ Crear divisiones personalizadas
No estás limitado a 3 panes. Puedes crear lo que quieras en cualquier momento.

Dentro de tmux, usa:

Ctrl+B , v → Divide el pane actual verticalmente (lado a lado)
Ctrl+B , s → Divide el pane actual horizontalmente (arriba/abajo)

Ejemplo: Empezar con 1 pane, dividir 3 veces:

🏷️ Renombrar ventanas y panes
Con muchas divisiones, es útil nombrarlas para no perder la cuenta.

Dentro de tmux:

Ctrl+B , , → Renombra la ventana actual
Luego escribe el nuevo nombre y presiona Enter

Por ejemplo:

agent1 # Primera ventana
agent2 # Segunda ventana
monitor # Monitor del sistema
🎨 Cambiar el layout de los panes
tmux tiene layouts predefinidos que reorganizan tus panes automáticamente:
Atajo Layout Aspecto
Ctrl+B Space Siguiente layout (ciclo) Cambia entre los disponibles
Ctrl+B ! Convertir pane en ventana Pone el pane en su propia ventana
Ctrl+B M Unir con otra ventana Combina dos ventanas
📨 Enviar comandos desde afuera de tmux
Puedes ejecutar comandos en una sesión de tmux sin estar conectado:
tmux send-keys -t ai-agents:0.0 "echo 'Hola desde afuera'" Enter

Desglose:

  • ai-agents = nombre de la sesión
  • :0 = número de la ventana
  • .0 = número del pane
  • "echo..." = comando a ejecutar
  • Enter = presionar Enter al final
💡 Caso de uso: Scripts que lanzan múltiples agentes en paralelo sin escribir manualmente en cada pane.
🤖 Automatizar con scripts
Puedes crear un script que lance todo automáticamente:
#!/bin/bash

# Crear sesión
tmux new-session -d -s ai-agents

# Pane 1: Agente processor
tmux send-keys -t ai-agents:0 "python agent-processor.py" Enter

# Pane 2: Agente monitor
tmux split-window -h
tmux send-keys -t ai-agents:0.1 "python agent-monitor.py" Enter

# Pane 3: Shell interactivo
tmux split-window -v
tmux send-keys -t ai-agents:0.2 "echo 'Shell listo'" Enter

# Conectar
tmux attach -t ai-agents
✅ Guarda esto en un archivo (p.ej. launch-agents.sh), haz que sea ejecutable con chmod +x launch-agents.sh, y ejecuta ./launch-agents.sh. Todo se lanza en paralelo.
⚙️ Personalizar tmux
Edita ~/.config/tmux/tmux.conf para cambiar comportamientos:
# Cambiar tecla prefijo (defecto es Ctrl+B)
set -g prefix C-a

# Desactivar focus-follows-mouse si prefieres hacer clic
set -g focus-follows-mouse off

# Cambiar colores
set -g status-bg "#1e1e2e"
set -g status-fg "#cdd6f4"

# Recargar después de editar:
tmux source-file ~/.config/tmux/tmux.conf
🔧 Troubleshooting Medio
❌ "No puedo conectarme a la sesión"
1

Verifica que la sesión existe

tmux list-sessions

Si no ves ai-agents, créala:

bash assets/scripts/init-tmux-sessions.sh create ai-agents
2

Intenta conectarte nuevamente

tmux a -t ai-agents
❌ "Focus-follows-mouse no funciona"
1

Recarga la configuración dentro de tmux

Ctrl+B : source-file ~/.config/tmux/tmux.conf

Presiona Ctrl+B, luego escribe el comando y presiona Enter.

2

Verifica que el mouse está activado

Dentro de tmux, en el prompt de comandos (:):

set -g mouse on
3

Prueba nuevamente

Mueve el ratón entre panes. Si sigue sin funcionar, tu terminal quizá no soporta mouse en tmux. Usa Ctrl+H/L/K/J en su lugar.

❌ "Los procesos se mataron al cerrar la terminal"
⚠️ Probable causa: No estabas dentro de tmux. Estabas escribiendo en una terminal normal y cerraste la terminal. Los procesos murieron.
1

Verifica que estás en tmux

En la terminal, ejecuta:

echo $TMUX

Si ve algo como /tmp/tmux-1000/default,1,0, estás dentro. Si está vacío, no lo estás.

2

Para asegurar que siempre abres una terminal dentro de tmux

Agrega esto a ~/.bashrc o ~/.zshrc:

if command -v tmux &>/dev/null; then
  if [[ -z "${TMUX}" ]]; then
    tmux attach -t ai-agents 2>/dev/null || tmux new-session -s ai-agents
  fi
fi
3

De ahora en adelante

Cada vez que abres una terminal, automáticamente entrará en la sesión tmux. Tus procesos siempre estarán protegidos.

❌ "Los plugins no se instalan"
1

Instala manualmente dentro de tmux

Ctrl+B I

(Mayúscula I de "Install")

2

Verifica que los plugins están instalados

ls ~/.config/tmux/plugins/

Deberías ver tpm, tmux-resurrect y tmux-continuum.

❌ "La persistencia no funciona (reinicio el PC y perdí las sesiones)"
1

Verifica que continuum está activado

grep continuum ~/.config/tmux/tmux.conf

Debería mostrar algo con continuum y on.

2

Verifica que hay backups guardados

ls -la ~/.cache/tmux-resurrect/

Si la carpeta está vacía, el backup nunca se guardó. Espera 15 minutos o reconfigura continuum.

3

Restaura manualmente

tmux a -t ai-agents
Ctrl+B Ctrl+R

(Restaurar sesión)
