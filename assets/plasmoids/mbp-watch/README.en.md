# MBP Watch KDE Plasmoid

KDE Plasma 6 plasmoid for `mbp-watch`.

Implementation location:

- `metadata.json`
- `contents/ui/`
- `contents/code/`
- `contents/config/`
- `contents/images/`

The package is installed per-user with `kpackagetool6` and integrated from `src/modules/bootstrap.sh`.
